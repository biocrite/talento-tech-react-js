# 🛍️ Multilingual E-Commerce App

A responsive, multilingual e-commerce application built with **React**. The project focuses on reusable components, localized routing, shared state management, and a responsive shopping experience.

## ✨ Features

- 🌍 **Multilingual interface**
  - Localized content
  - Localized URL slugs
  - Language-aware navigation

- 🛒 **Shopping cart**
  - Add and remove products
  - Persist cart data with `localStorage`
  - Shared cart state using React Context

- 📦 **Product pages**
  - Product listings
  - Dynamic product detail pages
  - Reusable product components

- 🧭 **Routing**
  - React Router
  - Centralized route configuration
  - Localized routes
  - Dynamic product routes
  - 404 / fallback handling

- 📱 **Responsive design**
  - Flexible product layouts
  - Mobile-friendly interface

- 📄 **Legal pages**
  - Multilingual Terms and Conditions
  - Multilingual Privacy Policy
